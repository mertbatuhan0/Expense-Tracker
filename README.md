# Expense Tracker API 🚀

A robust, fully tested, and containerized RESTful API built to track and manage personal expenses. This project serves as a comprehensive backend architecture demonstrating modern development practices including JWT authentication, data validation, pagination, and automated testing.

## ✨ Features

* **User Authentication:** Secure login and registration system using JWT (JSON Web Tokens).
* **Expense Management:** Full CRUD (Create, Read, Update, Delete) operations for personal expenses.
* **Pagination:** Optimized data retrieval using pagination for listing expenses, ensuring high performance even with large datasets.
* **Data Validation:** Strict payload and response validation using Pydantic schemas.
* **Comprehensive Testing:** Extensive test suite built with Pytest, covering both successful paths and edge cases (Unauthorized, Not Found, etc.).
* **Containerized Environment:** Fully dockerized setup for the application and PostgreSQL database, ensuring consistency across all environments.

## 🛠️ Tech Stack

* **Framework:** [FastAPI](https://fastapi.tiangolo.com/) (Python)
* **Database:** PostgreSQL
* **ORM:** SQLAlchemy
* **Data Validation:** Pydantic
* **Testing:** Pytest
* **Containerization:** Docker & Docker Compose
